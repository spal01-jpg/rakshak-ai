HOW TO RUN THE APPLICATION:
--------------------------------------------------------------------------------
OPTION 1 (Recommended - 1-Click Launch):
  Double-click "Rakshak_AI.exe" or "Start_Rakshak_AI.bat".
  - It automatically checks the backend server.
  - Launches Rakshak AI in a dedicated, native desktop application window.

OPTION 2 (Install Desktop Shortcut):
  Double-click "Install_Desktop_Shortcut.vbs".
  - Creates a "Rakshak AI" shortcut directly on your Windows Desktop with the
    official high-resolution crest icon.

OPTION 3 (Progressive Web App - Browser Install):
  Open http://127.0.0.1:8000 in Google Chrome or Microsoft Edge.
  Click "Install App" or "Download App" in the top navigation bar.

SYSTEM REQUIREMENTS:
--------------------------------------------------------------------------------
- Windows 10 or Windows 11 (64-bit)
- Python 3.10+ (if running backend locally from scratch)
- Edge or Chrome installed (for native desktop app mode)
